SUMMARY
Dataset: 12,200 FDA citizen petition documents (2000-2024)
Focus: Understanding how FDA justifies approval and denial decisions

We analyzed FDA reasoning patterns in 677 citizen petition responses
(2000-2024) containing explicit rationale text. Categories were developed
through a hybrid computational approach. First, TF-IDF analysis identified
distinctive phrases in approval vs. denial letters (e.g., 'listed drug'
appeared 147 times in approvals, 0 times in denials). Based on these
distinctive phrases, we defined 6 approval and 9 denial categories.

Next step (validation): We developed a multi-phrase scoring algorithm that counts occurrences of
category-specific phrases and assigns each document to the category with
the strongest textual evidence. To validate this approach, 1-2 people must manually
independently code a stratified random sample of 90 documents (30 approvals,
60 denials). We can then calculate the accuracy (%) of the automated categorization compared to manual coding, which would indicate substantial or moderate agreement. Specific steps can be found below.

COMPUTATIONALLY DISCOVERING PATTERNS IN FDA RESPONSES
1. TF-IDF Analysis
Purpose: Identify distinctive phrases in approvals vs denials

Method:
- Combined all approval texts into single corpus
- Combined all denial texts into single corpus
- Applied TF-IDF with n-grams (unigrams, bigrams, trigrams)
- Extracted top 30 distinctive terms for each category

FDA RESPONSE CATEGORIZATION METHODOLOGY
Categories were developed through a hybrid approach:

Step 1: Computational Discovery (TF-IDF)
  - Identified distinctive phrases in approval vs denial text
  - Found procedural language dominates denials (e.g., "cfr 10", "premature")
  - Found substantive language dominates approvals (e.g., "bioequivalence", "safety")

Step 2: Category Definition
  - Defined 6 approval categories based on distinctive phrases
  - Defined 9 denial categories (4 procedural, 4 substantive, 1 enforcement)
  - Categories align with FDA regulatory framework

Step 3: Multi-Phrase Scoring
  - For each category, defined 5-10 distinctive phrases
  - Scored each document by counting phrase occurrences
  - Assigned to category with highest score
  - Reported confidence: high (≥2 phrases), medium (1 phrase), low (0 phrases)

File: CATEGORY_DEFINITIONS.md 

APPROVAL CATEGORIES (6 total)
1. Bioequivalence/Therapeutic Equivalence
   Phrases: bioequivalent, BE study, therapeutic equivalence, AB-rated,
            listed drug, reference listed drug, ANDA, orange book

4. Public Health Benefit
   Phrases: public health, public interest, benefit, access, availability

5. FDA Concurrence
   Phrases: agree, granted, merit, warrant, appropriate, concur

6. Other Approval Reason
   (Catch-all for approvals not matching above)

DENIAL CATEGORIES (9 total)

Categorization Implementation
Script: categorize_all_enhanced.py

Process:
1. Load fda_rationales_dataset.csv (678 documents)
2. For each document:
   a. Convert rationale text to lowercase
   b. Count occurrences of phrases for each category
   c. Assign to category with highest phrase count
   d. Set confidence: high (≥2 phrases), medium (1), low (0)
   e. Record key phrases found
3. Save categorized results

Output: fda_rationales_enhanced_categories.csv
        - All 677 documents with assigned categories
        - Includes: Enhanced_Category, Confidence, Key_Phrases

Manual Coding Protocol
---------------------------
Instructions for human coder:

1. Open validation_sample_for_manual_coding.csv
2. For each document:
   a. Read Rationale_Text carefully
   b. Consult CATEGORY_DEFINITIONS.md
   c. Assign ONE category based on PRIMARY reasoning
   d. Enter category name in Manual_Category column
   e. Add any notes in Manual_Notes column
   f. Enter your initials in Coder_Initials column
3. Save file as validation_sample_CODED.csv

Coding Guidelines:
- Choose the DOMINANT reason if multiple present
- Use exact category names from CATEGORY_DEFINITIONS.md
- If truly ambiguous, note in Manual_Notes

Reference: CATEGORY_DEFINITIONS.md (complete category descriptions)
